# Проверка языков и голосов Silero

Проверка 11 октября 2026 года: 36 встроенных языковых маршрутов.
Сверка с [официальной документацией](https://github.com/snakers4/silero-models/blob/d9355348e2781dc8fa25a135d1602c530afae24c/README.md)
и списками speakers из пакетов, проверенных по SHA256. Снимок списков и
официальная разметка пола находятся в `testdata/silero/routing.json`.

## Исправления

- Английский по умолчанию направлялся в `v3_en_indic` / `tamil_female` или
  `tamil_male`. Теперь используется стандартная `v3_en` / `en_0`.
  Пол индексированных английских голосов upstream не указывает: оба режима
  используют выбранный голос с предупреждением. `TTS_STRICT_GENDER=1`
  требует явного проверенного выбора пользователя. Конкретный региональный
  акцент (`en-US`, `en-GB`, `en-IN`) этим маршрутом не гарантируется.
- Для `b_kjh`, `b_mhr`, `b_nog` подтверждён женский пол по таблице upstream;
  регрессионный тест защищает правильную разметку.
  Неподдерживаемый пол вызывает понятную ошибку, без подмены голосом другого языка.
- Добавлен `rajasthani_male`: в README upstream второй раз указан female,
  но проверенный пакет `v4_indic` содержит мужской голос.
- Остальные выбранные модели и языки соответствуют документации; каждый выбранный
  speaker существует в проверенном пакете. Пример конфигурации английского
  в README также больше не предлагает индийскую модель.

## Воспроизводимая проверка

```bash
python3 -m pip install ".[silero,indic]"
python3 silero_routing_regression.py --output /tmp/silero-routes
```

Команда проверяет реальный синтез каждого выбранного голоса и создаёт WAV/JSON.
Модели запускаются в отдельных процессах, чтобы память освобождалась между
пакетами. Проверяется выбор языка/модели/голоса, преобразование индийских письменностей,
формат WAV и непустой PCM. Для кириллического многоязычного пакета используется
общая проба «Тест.», а не оценка произношения на каждом языке. Бенгальская проба
для манипури проверяет обработку письменности, а не качество манипурского текста.
Автоматическая проверка не заменяет прослушивание носителями языка и не
гарантирует субъективное качество акцента; эта оценка остаётся открытой.
При запуске проверки в CI WAV и JSON включаются в артефакт модельной проверки.

Новые модель/голос меняют ключ PCM-кеша; индийское английское аудио не будет
использовано повторно. Существующий bookmark привязан к голосу, поэтому после
смены модели чтение начинается сначала. Пользовательский TTS_VOICE_CONFIG
имеет приоритет над встроенными маршрутами.
